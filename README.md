## 🇬🇧 English Version

Welcome to the project showcase for **[doradcanetia.pl](https://doradcanetia.pl)**. 

*Please note: This repository serves as a portfolio piece to present the project details. The source code is kept private.*

### 📖 About the Project
I designed and developed this website from scratch for a Netia sales advisor. The primary goal was to create a modern, lightning-fast, and highly converting website that provides a seamless user experience across all devices while maintaining top-tier SEO standards.

### 🚀 Live Website
You can visit the live website here: **[doradcanetia.pl](https://doradcanetia.pl)**

### 🛠️ Technologies Used
I chose a modern web stack to ensure the best possible performance and developer experience:
*   **[Astro.js](https://astro.build/):** The core framework used for Static Site Generation (SSG). Selected specifically for its "zero-JS by default" approach, which guarantees blazing-fast load times.
*   **HTML5 & TailWindCss:** For semantic structure and custom styling. *
*   **TypeScript:** For lightweight interactivity where needed.

### ✨ Key Highlights
*   **Exceptional Performance:** Achieved near-perfect scores in Google PageSpeed Insights thanks to Astro's architecture.
*   **SEO Optimized:** Built with a strong focus on technical SEO, including semantic HTML, optimized metadata, and fast loading speeds to ensure high search engine visibility.
*   **Fully Responsive UI:** A mobile-first design that adapts perfectly to smartphones, tablets, and desktop screens.

## 🇵🇱 Wersja Polska

### 📖 O projekcie
Zaprojektowałem i stworzyłem tę stronę od podstaw dla doradcy handlowego Netia. Głównym celem było dostarczenie nowoczesnej, błyskawicznie działającej i świetnie konwertującej witryny, która zapewnia doskonałe doświadczenia użytkownika na wszystkich urządzeniach, przy zachowaniu najwyższych standardów SEO.

### 🚀 Strona na żywo
Możesz odwiedzić działającą stronę tutaj: **[doradcanetia.pl](https://doradcanetia.pl)**

### 🛠️ Użyte Technologie
Wybrałem nowoczesny stack technologiczny, aby zapewnić najwyższą wydajność:
*   **[Astro.js](https://astro.build/):** Główny framework użyty do generowania statycznej strony (SSG). Wybrany ze względu na architekturę dostarczającą domyślnie zero JavaScriptu na front-endzie, co gwarantuje natychmiastowe ładowanie.
*   **HTML5 & TailWindCSS:** Semantyczna struktura i stylowanie. 
*   **TypeScript:** Do dodania lekkich, niezbędnych interakcji.

### ✨ Główne cechy
*   **Wyjątkowa wydajność:** Strona osiąga niemal perfekcyjne wyniki w Google PageSpeed Insights dzięki architekturze Astro.
*   **Optymalizacja SEO:** Zbudowana z silnym naciskiem na techniczne SEO, w tym semantyczny HTML, zoptymalizowane metadane i szybki czas ładowania, co zapewnia wysoką pozycję w wyszukiwarkach.
*   **Pełna responsywność:** Podejście mobile-first sprawia, że strona wygląda i działa idealnie na smartfonach, tabletach i komputerach.
